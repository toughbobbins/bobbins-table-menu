# Bobbins Table Menu


Basic Demo - https://youtu.be/ugdSaDWQDak
Dolmewood Integration - https://youtube.com/shorts/0gXG7L5uGls?feature=share


Build inter-linked quick launch dashboards of RollTables and Macros with a drag and drop text editor, styled buttons and one-click rolling to a popup or chat. Works with Bobbins Tables to create branching decision trees.

Requires Foundry v13. GM only.

## Install

In Foundry's Add-on Modules, choose Install Module and paste this manifest URL:

`https://github.com/toughbobbins/bobbins-table-menu/releases/latest/download/module.json`

## Use

1. In the RollTables sidebar, click **Open Menu List**, then **New Menu**.
2. Drag RollTables and Macros into the text. Each becomes a button. In live view, click one to roll the table or run the macro.
3. Right-click a chip to change its label, icon, border or layout. Click a chip to select it, then resize it from the size dropdown or press Delete.
4. The pen/eye button switches between editing and live view. The megaphone switches GM Roll, which whispers results to GMs.
5. The "..." menu has Send to Chat, Build Popup Macro and Build Chat Macro (saved in a "Table Launcher Macros" folder), Dark/Light and Delete Menu.
6. Menus can link to each other creating an ecosystem of launchers.

## Works with

- **Bobbins Tables:** rolls its tables, including decision trees. Decision trees need it enabled; simpler tables still roll without it.
- **Dynamic Table Manager:** its advanced tables roll even when it is switched off.

Module Settings has a Result Formatting option: plain text, or the other module's own formatting.
